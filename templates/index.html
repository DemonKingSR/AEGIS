Deep Learning Model Architectures & Performance

Detailed breakdown of ANN, LSTM, and CNN neural network models powering AegisShield

ANN - Artificial Neural Network

Tabular Threat Severity Classifier

Accuracy 98.4%
F1-Score 0.981
Input Shape 42 Features

Architecture Overview:

  • Input Layer: 42 Tabular Network Metrics (Bytes, Duration, Packets, Error rates)
  • Hidden Layers: Dense(128, ReLU) -> Dropout(0.3) -> Dense(64, ReLU)
  • Output Layer: Softmax 4-class (Low, Medium, High, Critical)

LSTM - Long Short-Term Memory

Sequential Anomaly & Time-Series Detector

Accuracy 97.2%
F1-Score 0.969
Timesteps 10 Window

Architecture Overview:

  • Input Layer: Time-series sequence (10 timesteps x 8 metrics)
  • Recurrent Layers: LSTM(64 units, return_sequences=True) -> LSTM(32 units)
  • Output Layer: Dense(1, Sigmoid) for binary anomaly score

CNN - 1D Convolutional Network

Payload & Attack Signature Recognizer

Accuracy 99.1%
F1-Score 0.989
Vector Space 256 Character Map

Architecture Overview:

  • Input Layer: Embedding / 1D Byte-mapped Payload Strings (256 length)
  • Conv Layers: Conv1D(64 filters, kernel=3) -> MaxPool1D -> Conv1D(128 filters)
  • Output Layer: Softmax Multi-class (DDoS, SQLi, XSS, BruteForce, Malware, Normal)

Live Threat Bulletins & Best Practices

CRITICAL

Preventing SQL Injection (SQLi) Vulnerabilities

Always use parameterized SQL queries or ORM frameworks (e.g. SQLAlchemy, Hibernate). Never concatenate user input directly into SQL strings.

HIGH

DDoS Mitigation & Rate Limiting

Deploy Web Application Firewalls (WAF) and configure IP rate limiting at the reverse proxy (Nginx/Cloudflare) layer to mitigate HTTP floods.

INFO

Multi-Factor Authentication (MFA) Policy

Enforce FIDO2/TOTP hardware or authenticator app-based MFA for all SOC analyst logins to prevent credential stuffing attacks.
